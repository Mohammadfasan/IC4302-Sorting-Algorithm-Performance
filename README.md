
# IC4302 - Sorting Algorithm Performance Analyzer

## Project Overview
This is a Java application developed for the IC4302 Programming III group assignment at the University of Colombo.

The application allows users to upload a CSV dataset, select a numeric column, and compare the execution times of five sorting algorithms.

## Sorting Algorithms
- Insertion Sort
- Shell Sort
- Merge Sort
- Quick Sort
- Heap Sort

## Technologies
- Java 21
- JavaFX
- Apache Maven
- GitHub

## Project Features
- CSV file upload
- Numeric column selection
- Dataset preview
- Dark and light mode
- Sorting performance comparison (planned)
- Fastest algorithm identification (planned)

## Team Collaboration
The project is developed by two group members using separate GitHub branches.

## Run the Application
cd sorting-analyzer

mvn clean javafx:run
